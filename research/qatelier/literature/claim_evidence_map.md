# QAtelier claim-to-evidence map

This map is a preregistration aid. It separates literature-supported statements from hypotheses that require new QAtelier artifacts. A citation in this file means the source supports the bounded statement shown in the same row; it does not authorize a stronger paraphrase.

## Claim classes

- **LIT**: bounded statement supported by a verified primary source.
- **TEST**: QAtelier hypothesis that requires a preregistered experiment.
- **NEW**: an empirical result that can only be claimed after the named artifact exists.
- **PROHIBITED**: wording that must not be used without additional evidence.

## Minimum evidence bundle for the paper's central claim

The central C2 claim may not be drafted from a single accuracy table. It requires, at minimum:

1. A frozen representation and train-only compressor manifest shared by all heads.
2. Per-seed held-out and OOD results for strong classical and quantum models on identical examples.
3. A spectrum/Fourier-matched classical surrogate with an explicit feature/coefficient budget.
4. An MPS/tensor-network control and a strong RBF/polynomial reference.
5. Entanglement, coordinate-rotation, and interaction-order ablations.
6. Kernel alignment/effective-rank and gradient/trainability diagnostics.
7. A complete audit trail showing that test labels and hardware outputs were not used for selection.

If any item is missing, the wording must fall back to C0 or C1 and describe the missing mechanism evidence explicitly.
