# Frozen document-QA corpus

`Project.md`, `myNotes.md`, `EVAL.md`, and `WRITEUP.md` are preserved here
because the historical document-QA and combined evaluation suites use them as
fixed inputs. They are not current project documentation and must not be used
as the operational manual or model inventory.

Use the repository-level guides instead:

- [`docs/START_HERE.md`](../../../../docs/START_HERE.md)
- [`docs/ATELIER_OPERATOR_GUIDE.md`](../../../../docs/ATELIER_OPERATOR_GUIDE.md)
- [`docs/WORKING_WITH_DOCUMENTS.md`](../../../../docs/WORKING_WITH_DOCUMENTS.md)

Add new evaluation tasks and corpus material without rewriting these files;
changing a frozen input changes the meaning of the historical benchmark.
