# Glossary

- **Prefill:** processing the prompt and building the KV cache.
- **Decode:** generating output tokens sequentially from the cached state.
- **TTFT:** time to first token.
- **KV cache:** stored keys and values reused during autoregressive decoding.
- **RAG:** retrieval-augmented generation.
- **ReAct:** an agent loop that alternates reasoning, actions, and observations.
- **Token fertility:** tokens required per unit of text; lower is more compact for a fixed tokenizer.
- **Unified memory:** Apple Silicon memory shared by CPU and GPU.
