# Archived Atelier documentation

This directory contains historical implementation records, not operating
instructions. They are retained for provenance and release archaeology.

For the current system, use:

- [`START_HERE.md`](../START_HERE.md) — choose a workflow.
- [`ATELIER_OPERATOR_GUIDE.md`](../ATELIER_OPERATOR_GUIDE.md) — run Atelier.
- [`WORKING_WITH_DOCUMENTS.md`](../WORKING_WITH_DOCUMENTS.md) — ingest and understand documents.
- [`CURRENT_ARCHITECTURE.md`](../CURRENT_ARCHITECTURE.md) — current implementation.
- [`ATELIER_WORKBENCH_PLAN.md`](../ATELIER_WORKBENCH_PLAN.md) — current product roadmap.

The archived step reports describe how the v1.0 system was built. They should
not be used as a model or command inventory.
